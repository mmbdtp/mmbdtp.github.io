Markdown is a simple way to write formatted text using a plain text file (with extension `.md`). 
We use it for this website, and you will use it for your `notebook.md`.

For each element below you will find the **text you type** and the **result**.

## Headings

```markdown
# Title
## Section
### Subsection
```

Use `#` for the title, `##` for sections, `###` for subsections (one `#` more for each level). 
Always leave a space after the `#`.

## Paragraphs and line breaks

```markdown
This is the first paragraph.
This is also part of the first paragraph.

This is the second paragraph: only a blank line separates paragraphs.
```

This is the first paragraph.
This is also part of the first paragraph.

This is the second paragraph: only a blank line separates paragraphs.

> A single line break in the text does **not** create a new line in the result: leave an empty line, or end the line with two spaces.

## Bold, italic and inline code

```markdown
This is **bold**, this is *italic*, and this is ***both***.
The species name is *Escherichia coli*.
Run the command `seqfu stats` on the file `reads.fastq.gz`.
```

This is **bold**, this is *italic*, and this is ***both***.
The species name is *Escherichia coli*.

## Code blocks

Put your code between three backticks, and (optionally) write the language after the first three backticks:

````markdown
```bash
cd /shared/team/2026_training/week2/{firstname}
seqfu stats --basename reads/*.fastq.gz > stats.tsv
```
````

```bash
cd /shared/team/2026_training/week2/{firstname}
seqfu stats --basename reads/*.fastq.gz > stats.tsv
```

Use this for **commands** and for **file contents**: it keeps the spacing and prevents characters like `*` or `_` from being interpreted as formatting.

## Links and images

```markdown
[Seqfu documentation](https://telatin.github.io/seqfu2/)

![Alternative text](figure.png)
```

[Seqfu documentation](https://telatin.github.io/seqfu2/)

An image is a link preceded by `!`. The image file must be reachable from the page (for example in the same directory).

## Quotes

```markdown
> What differences do you notice between the two datasets?
```

> What differences do you notice between the two datasets?

We use quotes for questions and notes.

## Tables

Tables in markdown are "drawn" with pipes (`|`) and dashes (`-`) like so:
```markdown
Sample | Reads | Organism
-------|-------|---------
DTP1-1 | 2.9 M | Yeast
DTP1-2 | 3.1 M | Lambda
```

Sample | Reads | Organism
-------|-------|---------
DTP1-1 | 2.9 M | Yeast
DTP1-2 | 3.1 M | Lambda

The line of dashes after the first row is required. 
The columns do not need to be aligned in the text file.

## Escaping

To show a special character literally, put a backslash before it:

```markdown
2 \* 3 = 6, and file\_name.txt
```

2 \* 3 = 6, and file\_name.txt

## Quick reference

You type                | You get
------------------------|----------------------
`# Title`               | Heading level 1
`**text**`              | **bold**
`*text*`                | *italic*
`` `code` ``            | `code`
`* item`                | Bullet list
`1. item`               | Numbered list
`[text](url)`           | Link
`> text`                | Quote
`---`                   | Horizontal line
