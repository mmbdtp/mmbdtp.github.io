:bulb:For our CLIMB tutorial you will find these tools installed in `/shared/team/conda/telatin.mmb-dtp/qc`

### SeqFu

| | |
|---|---|
| **URL** | [github.com/telatin/seqfu2](https://github.com/telatin/seqfu2) |
| **Conda** | `conda install -c conda-forge -c bioconda seqfu` |
| **Description** | General-purpose toolkit for FASTQ/FASTA manipulation, statistics, and quality inspection |

### FastQC

| | |
|---|---|
| **URL** | [bioinformatics.babraham.ac.uk/projects/fastqc](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/) |
| **Conda** | `conda install -c bioconda fastqc` |
| **Description** | Quality control reports for raw Illumina sequencing reads |

### fastp

| | |
|---|---|
| **URL** | [github.com/OpenGene/fastp](https://github.com/OpenGene/fastp) |
| **Conda** | `conda install -c bioconda fastp` |
| **Description** | Fast all-in-one preprocessing and QC for Illumina FASTQ files (trimming, filtering, adapter removal) |

### fastplong

| | |
|---|---|
| **URL** | [github.com/OpenGene/fastplong](https://github.com/OpenGene/fastplong) |
| **Conda** | `conda install -c bioconda fastplong` |
| **Description** | Preprocessing and QC for long-read sequencing data (ONT/PacBio), analogous to fastp |

### NanoPlot

| | |
|---|---|
| **URL** | [github.com/wdecoster/NanoPlot](https://github.com/wdecoster/NanoPlot) |
| **Conda** | `conda install -c bioconda nanoplot` |
| **Description** | Plotting and statistics for Oxford Nanopore sequencing data |

### Kraken2

| | |
|---|---|
| **URL** | [github.com/DerrickWood/kraken2](https://github.com/DerrickWood/kraken2) |
| **Conda** | `conda install -c bioconda kraken2` |
| **Description** | Taxonomic classification of sequencing reads using k-mer matching against a reference database |

### MultiQC

| | |
|---|---|
| **URL** | [multiqc.info](https://multiqc.info) |
| **Conda** | `conda install -c bioconda multiqc` |
| **Description** | Aggregates QC reports from multiple tools and samples into a single interactive HTML report |
